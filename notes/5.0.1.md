# Focus Palm 5.0.1 — Updater-ready baseline

This release preserves the public Focus Palm 5.0.1 experience and adds the secure infrastructure required to discover and install future direct-download Android updates.

No Focus 6.0 functionality is included.

## Português

- Experiência e funcionalidades públicas do Focus 5.0.1 preservadas.
- Preparação segura para futuras atualizações pelo próprio aplicativo.
- Validação de hash, pacote, versão e certificado.
- Dados e autenticação preservados durante atualizações compatíveis.

## English

- Public Focus 5.0.1 experience and features preserved.
- Secure preparation for future in-app direct-download updates.
- Hash, package, version, and certificate validation.
- Data and authentication preserved across compatible updates.
