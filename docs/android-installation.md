# Installing Focus Palm on Android

## First installation

1. Download the APK from the official Focus Site or this repository's Releases page.
2. Open the downloaded APK.
3. If Android requests permission, allow your browser or file manager to install apps from this source.
4. Review the Android installation prompt and tap **Install**.
5. Open Focus Palm and sign in.

## Future updates

A compatible direct-download installation can:

1. check the stable manifest;
2. show the new version and release notes;
3. download the signed APK;
4. verify its integrity and identity;
5. open the official Android installer.

Android always requires the user to confirm installation.

## Data preservation

Installing a newer official APK over an older official APK preserves application data when both use the same package and signing certificate. Do not uninstall the previous version when performing an update.

## Troubleshooting

If Android reports an incompatible signature, stop. Do not uninstall the existing application until its data is synchronized or backed up.
